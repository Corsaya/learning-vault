# Unit 1 — Atomic Structure and Properties
**Exam Weight: 7–9%**

## MCQ Pattern Recognition

| If you see...                                 | It's testing...                     | Key move                                                                                  |
| --------------------------------------------- | ----------------------------------- | ----------------------------------------------------------------------------------------- |
| Average atomic mass with two isotopes         | Weighted average calculation        | $M_{avg} = (\%_1/100)(M_1) + (\%_2/100)(M_2)$                                             |
| Mass spectrum — two peaks                     | Isotope identification              | x-axis = mass/charge ≈ mass number; height = relative abundance                           |
| "Which has the greatest molar mass?"          | Mole/mass conversions               | Convert to g/mol using periodic table                                                     |
| Large jump between consecutive IEs            | Number of valence electrons         | Jump is between last valence and first core electron; count IEs before jump               |
| Comparing first IE across a period            | Periodic trend with exceptions      | IE generally increases left → right; exceptions: Be > B (2s full), N > O (half-filled 2p) |
| Comparing atomic radius                       | Nuclear charge vs. shielding        | Radius decreases across period (more Z), increases down group (new shell)                 |
| PES spectrum — peak heights and energies      | Electron configuration confirmation | Peak height = number of electrons at that energy; lowest BE = valence electrons           |
| "Electron configuration of ion"               | Removing/adding electrons           | Cations lose from highest n first (for transition metals, 4s before 3d)                   |
| Empirical formula from mass percent           | Percent → moles → ratio             | Divide each percent by molar mass → divide all by smallest → round to integers            |
| Molecular formula from empirical + molar mass | Integer multiple check              | MM / empirical formula mass = multiplier; apply to all subscripts                         |

## FRQ Pattern Recognition

| Part says... | It's asking for... | Key move |
|---|---|---|
| "Determine the empirical formula" | Percent → mol → ratio | Assume 100 g, convert % to mol, divide by smallest |
| "Explain the trend in first IE" | Effective nuclear charge reasoning | Across period: more Z, same shielding → higher IE. Down group: more shielding → lower IE |
| "Identify the element from the IE data" | Jump = end of valence shell | Count IEs before the large jump |
| "Explain the PES spectrum" | Relate peaks to electron config | Low BE = valence (outermost); high BE = core; height ∝ electrons |

## AP Answer Templates

> **IE trend (period):** "Moving across the period, the nuclear charge increases while the electrons are added to the same subshell, providing little additional shielding. The greater effective nuclear charge increases the attraction on the outermost electrons, requiring more energy to remove them."

> **IE trend (group):** "Moving down the group, each successive element has an additional electron shell between the valence electrons and the nucleus. The increased shielding reduces the effective nuclear charge felt by the outermost electrons, lowering the first IE."

> **Empirical formula:** "Assuming 100 g: [element A] = X g ÷ MM_A = n_A mol; [element B] = Y g ÷ MM_B = n_B mol. Ratio n_A/n_B = [simplest integer ratio]. Empirical formula: A_x B_y."

## Critical Reminders

- Moles = mass (g) ÷ molar mass (g/mol). Molar mass = mass of one mole = same number as atomic mass in amu but in g/mol.
- Isotopes differ in neutron number only — same element, same proton count, different mass.
- Average atomic mass is a weighted average — not a simple average — use abundances as decimals.
- IE exceptions at Be/B and N/O: Be has a full 2s (harder to ionize than expected); N has a half-filled 2p (extra stability).
- PES: lower binding energy peaks = outer (valence) electrons. Higher BE = inner (core) electrons.
- Cation electron configurations: remove electrons from highest n first. Fe ([Ar]3d⁶4s²) → Fe²⁺ ([Ar]3d⁶), not [Ar]3d⁴4s².

# Unit 2 — Molecular and Ionic Compound Structure
**Exam Weight: 7–9%**

## MCQ Pattern Recognition

| If you see... | It's testing... | Key move |
|---|---|---|
| Lewis structure — central atom | Formal charge minimization | FC = valence e⁻ − nonbonding e⁻ − ½(bonding e⁻); minimize magnitude |
| "Which resonance structure is more stable?" | Formal charge distribution | Prefer structure where negative FC is on more electronegative atom |
| Counting sigma and pi bonds | Bond type identification | Single bond = 1σ; double bond = 1σ + 1π; triple bond = 1σ + 2π |
| Hybridization from structure | Electron group counting | 2 groups = sp; 3 = sp²; 4 = sp³; 5 = sp³d; 6 = sp³d² |
| Bond angle — lone pairs present | VSEPR lone-pair compression | Each LP compresses bond angles ~2.5°; 4 LP groups → ~104.5° (H₂O), 3 → ~107° (NH₃) |
| "Is the molecule polar?" | Dipole vector addition | Polar bonds in symmetric geometry → cancel → nonpolar molecule (CO₂, CCl₄, BF₃) |
| Lattice energy comparison | Charge and ionic radius | Higher charge or smaller ions → stronger lattice → higher MP, harder, less soluble |
| Metallic bonding properties | Sea of electrons model | Conductivity (mobile e⁻), malleability (layers slide), luster (e⁻ reflect light) |
| Alloys — properties change | Disruption of regular lattice | Substitutional (similar size) or interstitial (smaller atoms) alloys affect hardness |

## FRQ Pattern Recognition

| Part says... | It's asking for... | Key move |
|---|---|---|
| "Draw the Lewis structure" | Correct connectivity + octets + LP | Count total valence e⁻; minimize FC; expand octet for period 3+ if needed |
| "Predict the geometry" | Electron groups → molecular shape | Count ALL electron groups (bond + LP); LP don't appear in name but compress angles |
| "Explain why [molecule] is polar/nonpolar" | Bond polarity + symmetry | Polar bonds + asymmetric geometry = polar. Symmetric = nonpolar regardless of bond polarity |
| "Compare lattice energies" | Charge × charge / radius | Higher charges or smaller radii → stronger attraction → higher lattice energy |
| "Explain metallic bonding" | Delocalized electron sea | Metal cations in sea of mobile electrons; explains conduction, malleability, luster |

## AP Answer Templates

> **Lewis structure formal charge:** "The formal charge on [atom] = valence electrons − nonbonding electrons − ½(bonding electrons) = [n] − [n] − ½([n]) = [value]. The preferred resonance structure has the negative formal charge on [more electronegative atom]."

> **Molecular geometry:** "The central atom has [n] bonding pairs and [n] lone pairs, giving [n] total electron groups. By VSEPR, the electron geometry is [tetrahedral/etc.] and the molecular geometry is [name]. Bond angles are approximately [value]° because lone pairs exert greater repulsion than bonding pairs."

> **Molecular polarity:** "The [molecule] has [polar/nonpolar] bonds, and the molecular geometry is [shape]. The bond dipoles [cancel/do not cancel] due to [symmetric/asymmetric] geometry, so the molecule is [polar/nonpolar]."

## Critical Reminders

- Formal charge: FC = (valence e⁻) − (nonbonding e⁻) − ½(bonding e⁻). Sum of all FCs = overall charge of species.
- Expanded octets only for central atoms in period 3 or higher (d orbitals available).
- Electron geometry vs. molecular geometry: electron geometry counts lone pairs; molecular geometry names only the atom positions.
- Single bonds = σ only. Every additional bond (double, triple) adds one π bond.
- Polar molecule: needs both (1) polar bonds AND (2) asymmetric arrangement of those bonds.
- Lattice energy: proportional to (cation charge × anion charge) / (sum of ionic radii). Higher charge dominates over radius.
- Metallic bonding: explains malleability (layers slide without breaking), conductivity (free e⁻), and variable melting points.

# Unit 3 — Intermolecular Forces and Properties
**Exam Weight: 18–22% — HIGHEST WEIGHT**

## MCQ Pattern Recognition

| If you see... | It's testing... | Key move |
|---|---|---|
| Comparing boiling points of similar molecules | IMF strength hierarchy | LDF < dipole-dipole < H-bond. Heavier/more electrons = stronger LDF |
| H-bond identification | F, O, or N bonded directly to H | H-bond requires H directly bonded to F, O, or N (not just nearby) |
| "Which has higher vapor pressure?" | IMF strength — inverse relationship | Stronger IMF → higher BP → lower vapor pressure at any given T |
| Viscosity or surface tension comparison | IMF strength — direct relationship | Stronger IMF → higher viscosity, higher surface tension |
| Same formula, different BP (branched vs. linear) | Surface area and LDF | Linear > branched: more surface area → stronger LDF → higher BP |
| cis vs. trans isomer vapor pressure | Polarity difference | cis = polar (dipoles add) = stronger IMF = lower VP. trans = nonpolar = only LDF = higher VP |
| Gas behavior: PV/nRT > 1 | Repulsive molecular forces | High P: molecules too close → repulsions dominate → Z > 1 |
| Gas behavior: PV/nRT < 1 | Attractive molecular forces | Moderate P: attractions dominate → Z < 1 |
| Average molecular speed at same T | KMT and molar mass | Same T = same KE; lighter molecule = faster speed. u_rms ∝ 1/√M |
| Maxwell-Boltzmann: increasing T | Distribution shifts | Peak moves right (higher speed), broadens, height decreases; no molecules at zero |
| Beer-Lambert: concentration vs. absorbance | A = εlc | A directly proportional to c; dilution → lower A; same cuvette length |
| Chromatography — Rf or elution order | Polarity matching | Polar stationary phase: polar compound moves slower (higher affinity) → lower Rf |
| Solubility in water | Polarity matching + H-bond | Polar and H-bond capable = soluble. Nonpolar = insoluble ("like dissolves like") |
| Dissolving ionic compound | Ion-dipole IMF | Ion-dipole holds ions in solution; water orients O toward cation, H toward anion |

## FRQ Pattern Recognition

| Part says... | It's asking for... | Key move |
|---|---|---|
| "Explain the difference in boiling points" | IMF comparison | Name the dominant IMF for each; explain why one is stronger |
| "Identify the IMF between solute and solvent" | IMF type identification | Check polarity, H-bond capability, ion presence |
| "Explain the Beer-Lambert experiment result" | A = εlc reasoning | More concentrated → more light absorbed → higher absorbance |
| "Explain KMT and the observed pressure" | Molecular collisions | Pressure = force per area from collisions; more moles or higher T → more/harder collisions |
| "Why does real gas deviate?" | Van der Waals: a (attraction) or b (volume) | High P: volume matters (Z>1). Low-medium P: attractions matter (Z<1) |

## AP Answer Templates

> **IMF comparison:** "The [higher BP molecule] has stronger [intermolecular force type] than [lower BP molecule]. [Reason: e.g., H-bonded to N/O/F; more electrons → stronger LDF; larger surface area.] Stronger IMFs require more energy to overcome, resulting in a higher boiling point."

> **H-bond explanation:** "[Molecule X] can form hydrogen bonds because it has a hydrogen atom directly bonded to [F/O/N], which is highly electronegative. The partial positive H of one molecule is attracted to the lone pair on the [F/O/N] of an adjacent molecule."

> **Vapor pressure and IMF:** "The [molecule] with stronger [IMF type] has fewer molecules with sufficient kinetic energy to escape the liquid surface at a given temperature, resulting in a lower equilibrium vapor pressure."

> **Beer-Lambert dilution:** "Diluting the solution decreases the concentration of the absorbing species. By Beer-Lambert Law (A = εlc), absorbance is directly proportional to concentration, so the absorbance of the more dilute solution is lower."

## Critical Reminders

- IMF hierarchy: LDF < dipole-dipole < H-bond < ion-dipole. All molecules have LDF; it's additive with other IMFs.
- H-bond: H must be directly bonded to F, O, or N. A molecule with N, O, or F nearby (but H not bonded to it) does NOT H-bond through that atom.
- LDF increases with: more electrons (heavier atom/molecule), greater surface area (linear > branched).
- Temperature does NOT change which IMF a molecule has — it only determines whether KE overcomes IMFs.
- Beer-Lambert: A = εlc. Doubling concentration doubles absorbance. Changing path length l also changes A linearly.
- λmax is determined by the molecule's structure (chromophore), NOT by concentration or temperature.
- KMT: average KE = (3/2)RT (per mole). At the same T, all gases have the same average KE — lighter gases move faster.
- Maxwell-Boltzmann: area under curve = total number of molecules. Higher T → curve shifts right, broadens, peak lowers.
- Real gas: Z = PV/nRT. Z > 1: repulsions dominate (high P, large molecules). Z < 1: attractions dominate (moderate P, polar/large molecules).
- Solubility: ionic compounds dissolve in polar water via ion-dipole. Nonpolar solutes dissolve in nonpolar solvents via LDF-LDF.

# Unit 4 — Chemical Reactions
**Exam Weight: 7–9%**

## MCQ Pattern Recognition

| If you see... | It's testing... | Key move |
|---|---|---|
| Reaction produces white precipitate | Solubility rules + NIE | Identify insoluble product; write NIE with only ions that react |
| "Will a reaction occur?" (activity series) | Metal above = more reactive | Metal A displaces Metal B only if A is above B in activity series |
| Oxidation number changes in reaction | Redox identification | Species losing e⁻ = oxidized (OA gets higher ON); species gaining e⁻ = reduced (RA gets lower ON) |
| Balancing in acidic solution | Redox half-reaction method | Balance O with H₂O, balance H with H⁺, balance charge with e⁻ |
| Strong acid + strong base | Neutralization → water + salt | H⁺(aq) + OH⁻(aq) → H₂O(l); pH at equivalence = 7.00 |
| Titration: volume to reach equivalence | Moles acid = moles base | n_acid × M_acid × V_acid = n_base × M_base × V_base |
| Stoichiometry with limiting reagent | Find which reactant limits | Convert both reactants to moles of product; smaller answer = limiting |
| Concentration after dilution | C₁V₁ = C₂V₂ | ONLY valid for strong acids/bases or when equilibrium doesn't shift |
| Net ionic equation | Remove spectator ions | Spectators = ions fully in solution on both sides; keep solids, gases, water |
| "Identify the spectator ions" | Ions unchanged in NIE | Ions that appear on both sides of full ionic equation |

## FRQ Pattern Recognition

| Part says... | It's asking for... | Key move |
|---|---|---|
| "Write the balanced net ionic equation" | NIE format | Full ionic → remove spectators → check charge and atom balance |
| "Identify oxidizing/reducing agent" | Redox roles | OA = oxidizing agent (gets reduced, gains e⁻). RA = reducing agent (gets oxidized, loses e⁻) |
| "Predict whether a reaction will occur" | Activity series or solubility | Check activity series for displacement; check solubility rules for precipitation |
| "Calculate moles of product" | Stoichiometry from moles | mol product = mol limiting reagent × (coefficient ratio) |
| "Calculate concentration after mixing" | Dilution stoichiometry | n_solute conserved; [new] = n / V_total |

## AP Answer Templates

> **NIE format:** "Removing spectator ions [list them], the net ionic equation is: [NIE]. This equation shows only the species that undergo chemical change."

> **Redox identification:** "[Species X] is oxidized because its oxidation number increases from [+n] to [+m], meaning it loses electrons. [Species Y] is reduced because its oxidation number decreases from [+p] to [+q], meaning it gains electrons. Therefore [X] is the reducing agent and [Y] is the oxidizing agent."

> **Limiting reagent:** "Convert to moles: [reactant A] = [n] mol; [reactant B] = [n] mol. The stoichiometric ratio requires [ratio]. [Reactant A/B] is the limiting reagent because it would be consumed first. Moles of product = [calculation]."

## Critical Reminders

- Solubility rules apply in order — first matching rule wins. All Group 1 and NH₄⁺ compounds are always soluble.
- Activity series: Li, K, Ca, Na, Mg, Al, Zn, Fe, Ni, Sn, Pb, **H₂**, Cu, Ag, Au. Metals above H₂ react with acids.
- Strong acids (all 7): HCl, HBr, HI, HNO₃, H₂SO₄, HClO₄, HClO₃.
- In a NIE: soluble strong electrolytes are written as ions; weak acids, weak bases, solids, gases, water stay molecular.
- Oxidation number rules (in order): pure element = 0; monatomic ion = charge; F always −1; O usually −2 (−1 in peroxides); H is +1 with nonmetals.
- At the equivalence point (strong acid + strong base): pH = 7.00 exactly at 25°C. Neither ions hydrolyze.
- C₁V₁ = C₂V₂ gives concentration after dilution — moles of solute are conserved, only volume changes.

# Unit 5 — Kinetics
**Exam Weight: 7–9%**

## MCQ Pattern Recognition

| If you see... | It's testing... | Key move |
|---|---|---|
| Rate law from experimental data | Method of initial rates | Find two experiments where only one [reactant] changes; rate ratio = [conc ratio]ⁿ → solve for n |
| Graph: which plot is linear? | Rate order determination | [A] vs t = zero order; ln[A] vs t = first order; 1/[A] vs t = second order |
| Half-life is constant | First-order identification | Only first-order has constant t₁/₂ = 0.693/k |
| "Calculate k from half-life" | First-order: k = 0.693/t₁/₂ | k = 0.693 ÷ t₁/₂; units = time⁻¹ |
| Catalyst added — what changes? | Ea decreases; K unchanged | Rate increases; Ea decreases; ΔG°, ΔH°, and K are all unchanged |
| Energy diagram: Ea forward vs. reverse | Exo/endothermic identification | ΔH = Ea(forward) − Ea(reverse). Exothermic if products lower than reactants |
| Reaction mechanism — rate law | Slow step (RDS) determines rate | Rate law comes from the slow step; intermediates can be substituted |
| Arrhenius: ln k vs. 1/T graph | Ea from slope | Slope = −Ea/R; steeper negative slope = higher Ea = more temperature-sensitive |
| "Which condition increases rate?" | Collision theory | Higher T (more KE), higher concentration, surface area, or catalyst |
| Two-step mechanism — what is the intermediate? | Species produced in step 1, consumed in step 2 | Intermediate: appears as product then reactant. Catalyst: appears as reactant then product |

## FRQ Pattern Recognition

| Part says... | It's asking for... | Key move |
|---|---|---|
| "Determine the rate law" | Method of initial rates from table | Use data pairs where only one [reagent] changes to find each order |
| "Calculate the rate constant k" | Plug into rate law | k = rate / ([A]^m [B]^n); units depend on overall order |
| "Draw the energy diagram for the catalyzed reaction" | Lower Ea, same ΔH | Humps lower; start and end points unchanged |
| "Propose a mechanism consistent with the rate law" | Two-step mechanism | Slow step must give observed rate law; fast steps can have pre-equilibria |
| "Explain why doubling [A] quadruples the rate" | Second-order relationship | Rate ∝ [A]² → doubling [A] multiplies rate by 2² = 4 |

## AP Answer Templates

> **Rate law justification:** "Comparing Experiments [X] and [Y], [reactant A] doubles while [reactant B] is constant, and the rate [doubles/quadruples/is unchanged]. This indicates the reaction is [first/second/zero] order in [A]. Therefore the rate law is rate = k[A]^m[B]^n."

> **Catalyst explanation:** "A catalyst provides an alternative reaction pathway with a lower activation energy. More molecules have sufficient energy to react, increasing the rate. The catalyst does not change the overall energy difference between reactants and products (ΔH°) or the equilibrium constant K."

> **Temperature effect on rate (Arrhenius):** "According to the Arrhenius equation, increasing temperature increases k because more molecules have kinetic energy exceeding Ea. On an ln k vs. 1/T graph, the reaction with the larger Ea has a steeper (more negative) slope."

## Critical Reminders

- Rate law CANNOT be written from the balanced equation alone — it must come from experimental data (unless given an elementary step).
- Rate law uses only reactant concentrations (in the overall rate law — never products, unless specified as elementary).
- First-order only: constant half-life. t₁/₂ = 0.693/k. Independent of initial concentration.
- Second-order: t₁/₂ = 1/(k[A]₀) — depends on initial concentration.
- The overall rate is determined by the slowest step (rate-determining step).
- Catalyst: always lowers Ea, never changes ΔH°, ΔS°, ΔG°, or K. Appears in the mechanism but is regenerated.
- Intermediate: produced in one step, consumed in a later step. Never appears in the overall balanced equation.
- Arrhenius: ln k = ln A − Ea/RT. Higher Ea → greater sensitivity to temperature change → steeper slope on ln k vs. 1/T.

# Unit 6 — Thermochemistry
**Exam Weight: 7–9%**

## MCQ Pattern Recognition

| If you see... | It's testing... | Key move |
|---|---|---|
| Calorimetry: q = mcΔT | Identifying what m and c refer to | m = mass of solution (not solute alone); c = specific heat of solution |
| "Which releases more heat per gram?" | Heat per gram vs. per mole | Convert molar ΔH to per-gram by dividing by molar mass |
| Hess's Law: combining reactions | ΔH addition rules | Reverse → negate ΔH; multiply by n → scale ΔH; add reactions → add ΔH |
| Bond enthalpy calculation | ΔH = bonds broken − bonds formed | Apply to gas-phase only; count every bond, multiply by coefficients |
| "Is the reaction exo or endothermic?" (bond energies) | Energy released forming > breaking | Exothermic if forming bonds releases more energy than breaking costs |
| Enthalpy of formation | ΔH°rxn from ΔH°f values | ΔH°rxn = Σ ΔH°f(products) − Σ ΔH°f(reactants); elements in std state = 0 |
| Heat of phase change: q = nΔH | Flat regions on heating curve | During phase change, T is constant; q = n × ΔHfus or ΔHvap |
| "Minimum data for calorimetry" | Variables in q = mcΔT | Need: mass of solution, specific heat (often given), Ti and Tf |
| Heating curve — two flat regions | Phase change identification | First plateau = melting (solid→liquid); second plateau = boiling (liquid→gas) |

## FRQ Pattern Recognition

| Part says... | It's asking for... | Key move |
|---|---|---|
| "Calculate q for the reaction" | q = mcΔT | Use mass of solution and ΔT; sign: if T rises → exothermic → q < 0 for rxn |
| "Calculate ΔH° using Hess's Law" | Combine given reactions to match target | Reverse and/or scale reactions; track sign changes |
| "Estimate ΔH° using bond enthalpies" | Bonds broken − bonds formed | Count every bond in every molecule; multiply by stoichiometric coefficients |
| "Explain why the q value is an approximation" | Assumptions and heat loss | Assumes no heat loss to surroundings/calorimeter; c of solution ≈ c of water |
| "Calculate the enthalpy of fusion" | q = nΔHfus | n from mass/MM; rearrange q = mcΔT to find heat; then ΔHfus = q/n |

## AP Answer Templates

> **Calorimetry setup:** "q = mcΔT = ([mass of solution] g)(4.18 J/g·°C)([T_f − T_i]°C) = [value] J. The enthalpy of reaction = −q/n_solute = [value] kJ/mol. The sign is [positive/negative] because the temperature [increased/decreased], indicating the reaction is [exothermic/endothermic]."

> **Hess's Law:** "To obtain the target reaction, [Reaction 1 is reversed / multiplied by n], giving ΔH₁ = [value] kJ. [Reaction 2 is kept as written], giving ΔH₂ = [value] kJ. Adding the two reactions gives the target reaction, and ΔH° = ΔH₁ + ΔH₂ = [total] kJ."

> **Bond enthalpy:** "Bonds broken (reactants): [list bonds × count × BE] = [sum] kJ. Bonds formed (products): [list bonds × count × BE] = [sum] kJ. ΔH° = [broken total] − [formed total] = [value] kJ."

## Critical Reminders

- q = mcΔT: m is the mass of the SOLUTION (water + dissolved substance), not just the solute.
- Sign convention for calorimetry: if solution temperature rises, reaction is exothermic → ΔH_rxn is negative. q_solution = −q_reaction.
- Hess's Law: reverse a reaction → negate ΔH. Multiply all coefficients by n → multiply ΔH by n.
- Bond enthalpy applies only to gas-phase reactions. Phase changes for reactants/products add correction terms not in the bond table.
- ΔH°f = 0 for elements in their standard state (O₂(g), H₂(g), C(s,graphite), etc.). This is different from S° ≠ 0.
- Enthalpy is a state function: path doesn't matter, only initial and final states.
- During a phase change, temperature is constant — all energy goes into breaking/forming IMFs. q = n × ΔH_phase.
- The flat region at LOWER temperature on a heating curve = melting. The flat region at HIGHER temperature = boiling.

# Unit 7 — Equilibrium
**Exam Weight: 7–9%**

## MCQ Pattern Recognition

| If you see... | It's testing... | Key move |
|---|---|---|
| "Is the system at equilibrium?" from a graph | Flat concentration lines | Equilibrium = concentrations stop changing (flat lines). Equal concentrations ≠ equilibrium |
| Single particle diagram — is it equilibrium? | Snapshot limitation | ONE snapshot cannot confirm equilibrium — need at least two time points |
| Reverse the reaction — find new K | Reciprocal rule | K_new = 1/K_original |
| Double the coefficients — find new K | Power rule | K_new = K² |
| Add two reactions — find K | Multiplication rule | K_new = K₁ × K₂ |
| Q vs. K comparison | Shift direction | Q < K → forward; Q > K → reverse; Q = K → no shift |
| Inert gas added at constant volume | No shift trap | Partial pressures unchanged → Q unchanged → no shift |
| Volume decreased — which way does it shift? | Moles of gas comparison | Shift toward side with fewer moles of gas |
| Temperature increased, exothermic reaction | K changes | Exothermic: heating → K decreases (shifts left). Endothermic: heating → K increases |
| K >> 1 given | Essentially complete reaction | Products heavily favored; reactants nearly fully consumed |
| Ksp ICE table: AB₂ type | Stoichiometric coefficient in Ksp | Ksp = (s)(2s)² = 4s³; solve s = (Ksp/4)^(1/3) |
| Common ion added to saturated solution | Decreased solubility | Same ion in solution → Q > Ksp → precipitation; Ksp itself unchanged |

## FRQ Pattern Recognition

| Part says... | It's asking for... | Key move |
|---|---|---|
| "Predict the direction of shift" | Le Chatelier's principle | Identify the stress; apply Le Chatelier; state which direction relieves the stress |
| "Write the Kc expression" | Products over reactants with coefficients | Omit pure solids and pure liquids; gases and aqueous ions included |
| "Calculate Kp from Kc" | Kp = Kc(RT)^Δn | Δn = mol gas products − mol gas reactants; R = 0.08206 L·atm/mol·K |
| "Calculate molar solubility" | Ksp ICE table | Let s = molar solubility; express each ion in terms of s; substitute into Ksp |
| "Explain the common-ion effect" | Added ion suppresses dissolution | State that the added ion is a product of dissolution; Q rises above Ksp; equilibrium shifts left |

## AP Answer Templates

> **Le Chatelier shift:** "[Stress applied: e.g., adding product / decreasing volume] causes [Q to increase above K / Q to decrease below K]. The system shifts [forward/reverse] to [consume/produce] [species], partially relieving the stress and restoring Q = K."

> **Q vs. K prediction:** "Q = [products]^coeff / [reactants]^coeff = [calculation] = [value]. Since Q [</>] K = [value], the system must shift [forward/reverse] to reach equilibrium."

> **Ksp → molar solubility:** "Let s = molar solubility of [compound]. From the dissolution: [ion A] = [n]s and [ion B] = [m]s. Ksp = ([n]s)^a([m]s)^b = [expression in s]. Solving: s = [value] mol/L."

> **Common-ion explanation:** "The presence of [ion X] in solution (a product of dissolution) causes Q to exceed Ksp. The equilibrium shifts left, suppressing dissolution. The molar solubility decreases compared to pure water; however, Ksp itself is unchanged because temperature did not change."

## Critical Reminders

- Equilibrium = equal rates (forward and reverse), NOT equal concentrations. Flat graph = equilibrium.
- K depends ONLY on temperature. Concentration, pressure, and catalyst changes do not change K — only Q.
- Pure solids and pure liquids are EXCLUDED from K expressions. Only aqueous ions and gases are included.
- Inert gas at constant volume: no shift. Inert gas at constant pressure: volume increases → Q shifts toward more gas moles.
- Temperature effect: exothermic forward (ΔH < 0) → heating decreases K. Endothermic forward (ΔH > 0) → heating increases K.
- Reversing a reaction: K_new = 1/K. Multiplying coefficients by n: K_new = K^n. Adding reactions: multiply K values.
- Kp = Kc(RT)^Δn. If Δn = 0 (equal gas moles on both sides), then Kp = Kc.
- For Ksp with coefficient > 1: the ion concentration in the ICE Change row = (coefficient × s). The K expression raises it to that power. Both effects must be applied.
- 5% rule: if K is very small, approximate [reactant]_eq ≈ [reactant]₀. Verify: x/[A]₀ < 0.05.

# Unit 8 — Acids and Bases
**Exam Weight: 11–15%**

## MCQ Pattern Recognition

| If you see... | It's testing... | Key move |
|---|---|---|
| Strong acid concentration → pH | Complete dissociation | [H⁺] = [acid] exactly. No ICE table. pH = −log[acid] |
| Ba(OH)₂ or Ca(OH)₂ → pH | Diprotic base factor | [OH⁻] = 2 × [base]. Forgetting the ×2 is a full pH unit error |
| Neutral pH at T ≠ 25°C | Kw temperature dependence | Neutral = [H⁺] = [OH⁻] = √Kw. Neutral pH < 7 if T > 25°C |
| "Is pure water acidic at 55°C?" | Neutral definition | Neutral = [H⁺] = [OH⁻]; pure water is ALWAYS neutral regardless of temperature |
| Diluting a weak acid — % ionization | Dilution effect | [H⁺] decreases; % ionization increases. These trend OPPOSITE each other |
| Half-equivalence point on titration curve | pH = pKa | At half-equivalence, [HA] = [A⁻]; pH = pKa exactly |
| Equivalence point, weak acid/strong base | pH > 7 | Conjugate base hydrolyzes: A⁻ + H₂O ⇌ HA + OH⁻; pH > 7 |
| "Which is the stronger acid?" (oxyacids) | More oxygens = stronger | HClO₄ > HClO₃ > HClO₂ > HClO |
| "Which is the stronger acid?" (binary acids) | Bond strength down group | HI > HBr > HCl > HF (bond strength dominates, not EN) |
| More electronegative substituents | Inductive effect | More EN substituents → stabilize conjugate base → stronger acid |
| NF₃ vs. NH₃ as base | Substituent reduces lone pair availability | F withdraws electrons from N → NF₃ is much weaker base than NH₃ |
| pH above pKa | Dominant species | pH > pKa → [A⁻] > [HA]. pH < pKa → [HA] > [A⁻] |
| Buffer + strong acid added | Conjugate base neutralizes it | [A⁻] + H⁺ → HA; pH decreases slightly |
| CaF₂ dissolving in acid | pH effect on salt of weak acid | H⁺ protonates F⁻ → removes product → more CaF₂ dissolves |
| AgCl dissolving at different pH | Salt of strong acid | Cl⁻ is not protonated by H⁺; solubility unchanged |

## FRQ Pattern Recognition

| Part says... | It's asking for... | Key move |
|---|---|---|
| "Calculate the pH of a weak acid" | Ka ICE table | [H⁺] = √(Ka × C); check 5% approximation |
| "Calculate pH of buffer after adding NaOH" | Stoichiometry then H-H | Step 1: moles acid − moles base = moles remaining. Step 2: pH = pKa + log([A⁻]/[HA]) |
| "Determine pKa from titration curve" | Half-equivalence point | Find V_eq, divide by 2, read pH at that volume → pH = pKa |
| "Explain why the solution is basic/acidic at equivalence" | Salt hydrolysis | Conjugate base/acid of weak partner hydrolyzes water |
| "Explain why a buffer resists pH change" | Neutralization by conjugate pair | A⁻ neutralizes added acid; HA neutralizes added base; weak partner absorbs the change |
| "Identify the conjugate acid-base pair" | Differ by one H⁺ | Conjugate pairs: HA / A⁻; always differ by exactly one proton |

## AP Answer Templates

> **Weak acid pH:** "[HA] is a weak acid with Ka = [value]. ICE table gives [H⁺] = x, where Ka = x²/(C − x) ≈ x²/C. x = √(Ka·C) = [value] M. pH = −log(x) = [value]. (5% check: x/C = [value]% < 5% ✓)"

> **Henderson-Hasselbalch:** "After adding [moles] of NaOH: moles of HA remaining = [n_A]; moles of A⁻ formed = [n_B]. pH = pKa + log([A⁻]/[HA]) = [pKa] + log([n_B]/[n_A]) = [value]."

> **Equivalence point pH > 7:** "At the equivalence point, all the weak acid has been converted to its conjugate base A⁻. This conjugate base hydrolyzes: A⁻ + H₂O ⇌ HA + OH⁻, producing OH⁻ and making the solution basic (pH > 7)."

> **Buffer capacity direction:** "Adding strong acid: the conjugate base component (A⁻) reacts with H⁺: A⁻ + H⁺ → HA. Adding strong base: the weak acid component (HA) reacts with OH⁻: HA + OH⁻ → A⁻ + H₂O. In both cases, the pH changes only slightly because the strong acid/base is converted to the weak acid/base."

> **Acid strength structure:** "The [more electronegative / additional oxygen] substituent withdraws electron density from the O–H bond through induction, making the bond weaker and easier to ionize. A more stable conjugate base results, increasing Ka (decreasing pKa) and making it the stronger acid."

## Critical Reminders

- Strong acids dissociate COMPLETELY: pH = −log[acid]₀ directly. No Ka, no ICE table.
- Diprotic bases (Ca(OH)₂, Sr(OH)₂, Ba(OH)₂): [OH⁻] = 2 × concentration. Never forget the factor of 2.
- Neutral = [H⁺] = [OH⁻], always. At 25°C this means pH = 7.00; at higher T, neutral pH < 7.
- Henderson-Hasselbalch: pH = pKa + log([A⁻]/[HA]). Numerator is ALWAYS the conjugate base.
- ALWAYS do stoichiometry before H-H: convert added strong acid/base to moles; recalculate buffer components; then use H-H.
- Half-equivalence point: pH = pKa. This is the most tested fact about titration curves.
- Equivalence point (weak acid + strong base): pH > 7. Conjugate base hydrolyzes → basic solution.
- Binary acids down a group: acid strength increases (HI > HBr > HCl > HF) because bond strength decreases. Electronegativity alone predicts the wrong trend.
- Oxyacids: more O atoms on same central element → stronger acid (more inductive stabilization of conjugate base).
- pH > pKa: conjugate base dominates. pH < pKa: weak acid dominates. At pKa: equal amounts.
- Salts of weak acids (CaF₂, CaCO₃): more soluble at lower pH. Salts of strong acids (AgCl): pH-independent.

## Critical Reminders

- S° is NEVER zero — elements in standard state have positive S°. Unlike ΔH°f and ΔG°f (which are 0 for elements), S° is always > 0.
- Always convert ΔS from J/mol·K to kJ/mol·K before using T = ΔH/ΔS or ΔG = ΔH − TΔS.
- R = 8.314 J/(mol·K) in ΔG° = −RT ln K ONLY. Never use 0.08206 in this equation.
- Convert ΔG° to J/mol before plugging into ln K = −ΔG°/RT.
- Catalyst: lowers Ea, speeds rate, does NOT change ΔG°, ΔH°, ΔS°, or K. Ever.
- Coupled reactions FRQ: must name the common intermediate AND state ΔG°_overall < 0 for full credit.
- E° is intensive — NEVER multiply by a stoichiometric coefficient.
- E°cell = E°cathode − E°anode: use the given E° values directly; never flip their signs going into this formula.
- n in ΔG° = −nFE° comes from the balanced cell reaction, not the formula of the ion.
- E_cell = 0 at equilibrium (dead battery) — always, no calculation needed.
- Nernst at 25°C: E_cell = E°cell − (0.0592/n) log Q. At other T: use RT/nF · ln Q.
- Faraday chain: always convert time to seconds before q = It.
- H₂:O₂ = 2:1 mole ratio in electrolysis of water — MCQ trap.
- E°cell > 0 ↔ ΔG° < 0 ↔ K > 1: all three say "spontaneous." These are equivalent.
- When product ion precipitates out: [product] decreases → Q decreases → E_cell INCREASES above E°cell.
- Heat released depends on moles of **limiting reagent** only, not excess reagent conditions.
- Elements in standard state: ΔHf° = 0, ΔGf° = 0, but S° ≠ 0
- Always multiply S° and ΔH°f values by stoichiometric coefficients before summing.
- Negative ΔS always opposes thermodynamic favorability — the −TΔS term adds a positive contribution to ΔG.
