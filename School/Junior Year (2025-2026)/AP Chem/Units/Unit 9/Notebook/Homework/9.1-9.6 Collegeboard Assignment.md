## Q6. Haber Process FRQ — $\ce{N2(g) + 3H2(g) <=> 2NH3(g)}$

**Given:** $\Delta H^\circ = -92.2$ kJ/mol, $\Delta S^\circ = -198.8$ J/(mol·K)

**(a)(i)** Convert ΔS°: −198.8 J/(mol·K) = −0.1988 kJ/(mol·K). ΔG° = (−92.2) − (298)(−0.1988) = −92.2 + 59.24 = **−33.0 kJ/mol**

**(a)(ii)** Convert ΔG° to J: −33,000 J/mol. ln K = −(−33,000)/((8.314)(298)) = 13.32 → **Kp ≈ 6.1 × 10⁵**

**(b)** Bonds broken: x (N≡N) + 3(436) = x + 1308. Bonds formed: 6(391) = 2346. −92.2 = (x + 1308) − 2346 → **x = 946 kJ/mol** (lit. ≈ 945 ✓)

**(c)** The N≡N bond enthalpy (946 kJ/mol) is very high, requiring a large amount of energy to break it. This creates a very high Eₐ for the forward reaction. At 298 K, very few N₂/H₂ collisions have enough KE to exceed Eₐ, so the rate is extremely slow even though ΔG° < 0. The reaction is under **kinetic control**.

**(d)** ΔH° < 0 and ΔS° < 0 (−ΔH, −ΔS quadrant). The −TΔS° term is positive and grows with T. Above T = ΔH°/ΔS° = −92.2/−0.1988 = **464 K**, −TΔS° exceeds ΔH° in magnitude and ΔG° > 0. Unfavorable at high T.

**(e)** At high T, Kp < 1. Removing NH₃ keeps Qp = P²(NH₃)/[P(N₂)·P³(H₂)] very low → Qp < Kp → forward reaction continues. By constantly removing product, Qp never reaches Kp, driving continuous forward reaction even when ΔG° > 0.

**(f)** Error 1: Lower BP means **weaker** IMFs, not stronger. Error 2: H₂ is nonpolar → only **London dispersion forces** (weak, few electrons). NH₃ has N−H bonds with electronegative N → **hydrogen bonding** (much stronger). H₂ boils at 20 K, NH₃ at 240 K because of this IMF difference.

## Summary of Key FRQ Patterns

| Pattern | Rule |
|---|---|
| ΔG° calculation | ΔG° = ΔH° − TΔS°; convert ΔS° from J to kJ first |
| K from ΔG° | ΔG° = −RT ln K; use ΔG° in J, R = 8.314 J/(mol·K) |
| Four-quadrant favorability | −/+ → always; +/− → never; +/+ → high T; −/− → low T |
| Threshold T | Set ΔG° = 0 → T = ΔH°/ΔS° (units must match) |
| Bond enthalpy | ΔH° = Σ(broken) − Σ(formed); count every bond per molecule × coefficient |
| Kinetic control | ΔG° < 0 but high Eₐ → thermodynamically favored, kinetically slow |
| Catalyst effect | Lowers Eₐ, increases rate; no effect on ΔG°, ΔH°, ΔS°, or K |
| Q vs K shift | Q < K → forward; Q > K → reverse; removing product lowers Q |
| Combining K values | Reverse rxn → K becomes 1/K; add rxns → multiply K values |
| ΔS° prediction | Count moles of gas: more gas products = +ΔS°; less gas = −ΔS° |
