# APUSH — Progress Check Answer & Walkthrough Guide

This file is a skill prompt for Claude. When the student uploads screenshots of a Progress Check (MCQ or FRQ), follow the instructions below to produce the answer file and save it to the correct unit folder.

---

## Workflow on Upload

1. **Identify the unit** from the screenshot header or question content. Confirm with the student if unclear.
2. **Identify the type**: MCQ (`Progress Check MCQ/`) or FRQ (`Progress Check FRQ/Part 1/` or `Part 2/`).
3. **Produce the answer document** following the format below.
4. **Save it** to the correct path:
   - MCQ → `APUSH/Units/Unit N/Progress Check MCQ/Progress Check N MCQ Answers.md`
   - FRQ Part 1 → `APUSH/Units/Unit N/Progress Check FRQ/Part 1/Progress Check N FRQ Part 1 Answers.md`
   - FRQ Part 2 → `APUSH/Units/Unit N/Progress Check FRQ/Part 2/Progress Check N FRQ Part 2 Answers.md`

---

## MCQ Answer File Format

```
# Unit N — Progress Check MCQ Answers

---

## Question 1
> [Paste or transcribe the full question stem and all four answer choices exactly as written, labeled A–D.]

**Notes section:** [Which unit/topic this tests, e.g. "Unit 3 — Market Revolution & Sectionalism"]

**Key concept:** [1–2 sentences on what historical idea or skill this question is really testing.]

**Correct answer: [Letter] — [Choice text]**
[2–4 sentences explaining why this is correct. Be specific — name the event, policy, or trend that makes it right.]

**Why the others are wrong:**
- **[Letter]:** [Explanation. For clear cancels — wrong time period, opposite meaning, factually false — one sentence is enough. For close distractors, explain the subtle distinction.]
- **[Letter]:** [Same approach.]
- **[Letter]:** [Same approach.]

---

## Question 2
...
```

### MCQ Notes
- Head every question with the relevant notes section so the student knows exactly where to review.
- "Easily cancellable" wrong answers (anachronistic, factually opposite, wrong time period) get one sentence max — don't over-explain.
- Close distractors (half-right answers, true-but-irrelevant) deserve a fuller explanation of the distinction.
- Use the wrong answer pattern categories from the MCQ Stimulus Guide when applicable: Too Broad, Anachronistic, Half-Right, Extreme Language, True but Irrelevant.

## FRQ Answer File Format

```
# Unit N — Progress Check FRQ [Part 1 / Part 2] Answers

---

## FRQ Type: [DBQ / LEQ / SAQ]
[One paragraph describing the FRQ type: what it asks the student to do, how it's scored, and what the general approach should be. Pull from the relevant Skills guide (DBQ Guide, LEQ Guide, SAQ Guide) for context.]

---

## [Question or Prompt title, transcribed from screenshot]

**Notes section:** [Which unit/topic this tests.]

**What this prompt is asking:** [1–2 sentences breaking down the task — what historical argument or analysis is expected.]

---

### Part A (if applicable)
**Task:** [Restate the part's specific directive — "Briefly describe," "Explain one cause," etc.]

**Full answer:**
[Complete, scorable response written in the appropriate format for the FRQ type. For SAQ: 2–4 sentences with claim + evidence. For LEQ/DBQ: thesis + evidence structure. Write enough to earn full points.]

**To earn full credit:**
- [Bullet each scoring criterion and whether the answer above satisfies it.]

---

### Part B (if applicable)
[Same structure as Part A.]

---

### Part C (if applicable)
[Same structure as Part A.]

---

## Scoring Summary
| Part | Points Possible | What's Required |
|------|----------------|-----------------|
| A    | 1              | [Brief criterion] |
| B    | 1              | [Brief criterion] |
| C    | 1              | [Brief criterion] |
| **Total** | **3**   | |
```

### FRQ Notes
- Always identify and name the FRQ type (SAQ, LEQ, DBQ) at the top and briefly explain it — especially important because each has a different scoring rubric and approach.
- For SAQ: follow the claim → evidence → (optional) connection structure. No thesis required.
- For LEQ: include a scorable thesis, at least two pieces of specific evidence, and reasoning that connects evidence to argument.
- For DBQ: same as LEQ plus document analysis (HAPP — Historical context, Audience, Purpose, Point of view) where applicable.
- Head each part with its notes section reference so the student knows where to go for review.
- "Full points" criteria should be explicit — don't just write a good answer, explain what the rubric is looking for.

---

## General Rules

- **Never fabricate.** If you can't determine which unit a question belongs to from the screenshot content, ask before proceeding.
- **Transcribe exactly.** Copy question stems and answer choices word-for-word from the screenshot. Don't paraphrase.
- **Notes section headers are required on every question.** Cross-reference `APUSH/Units/Unit N/` note files to determine the right section. If a question spans topics, list the primary one.
- **Don't over-explain obvious cancels.** If a wrong answer is from the wrong century or is factually opposite, one sentence is enough.
- **Do go deep on close distractors.** If two answers are historically plausible but one is subtly wrong, explain the distinction clearly — that's where the learning is.
