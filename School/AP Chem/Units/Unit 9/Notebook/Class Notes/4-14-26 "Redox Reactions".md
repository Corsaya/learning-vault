## Topic 4.9 — Oxidation-Reduction Reactions

---

## Core Concepts

In a redox reaction, electrons transfer from one species to another. The species that **loses electrons** is **oxidized** (oxidation state increases); the species that **gains electrons** is **reduced** (oxidation state decreases). **OIL RIG** — Oxidation Is Loss, Reduction Is Gain.

Every redox reaction splits into two **half-reactions**. The overall equation must be balanced in both **atoms and charge**. Electrons produced in oxidation must equal electrons consumed in reduction — use the LCM to scale half-reactions before adding. **Spectator ions** (NO₃⁻, SO₄²⁻, Cl⁻, etc.) are dropped in the net ionic equation.

---

## Key Equations

**Oxidation half-reaction** (electrons on right):
$$\text{Metal} \rightarrow \text{Metal}^{n+} + ne^-$$

**Reduction half-reaction** (electrons on left):
$$\text{Ion}^{n+} + ne^- \rightarrow \text{Metal}$$

**Steps:**
1. Write both half-reactions
2. Find LCM of electron counts; scale each half-reaction
3. Add; cancel electrons
4. Drop spectator ions → net ionic equation

---

## Worked Examples

### Example 1 — Barium + Silver Nitrate
$$Ba \rightarrow Ba^{2+} + 2e^-$$
$$2(Ag^+ + e^- \rightarrow Ag)$$

$$\boxed{Ba_{(s)} + 2Ag^+_{(aq)} \rightarrow Ba^{2+}_{(aq)} + 2Ag_{(s)}}$$

NO₃⁻ is spectator — dropped.

### Example 2 — Iron + Copper(II) Sulfate
$$Fe \rightarrow Fe^{2+} + 2e^-$$
$$Cu^{2+} + 2e^- \rightarrow Cu$$

$$\boxed{Fe_{(s)} + Cu^{2+}_{(aq)} \rightarrow Fe^{2+}_{(aq)} + Cu_{(s)}}$$

Electrons already balance (2 = 2). SO₄²⁻ is spectator — dropped.

### Example 3 — Zinc + Gold(III) Chloride (LCM = 6)
$$3Zn \rightarrow 3Zn^{2+} + 6e^-$$
$$2Au^{3+} + 6e^- \rightarrow 2Au$$

$$\boxed{3Zn_{(s)} + 2Au^{3+}_{(aq)} \rightarrow 3Zn^{2+}_{(aq)} + 2Au_{(s)}}$$

### Example 4 — Aluminum + Nickel(II) Nitrate (LCM = 6)
$$2Al \rightarrow 2Al^{3+} + 6e^-$$
$$3Ni^{2+} + 6e^- \rightarrow 3Ni$$

$$\boxed{2Al_{(s)} + 3Ni^{2+}_{(aq)} \rightarrow 2Al^{3+}_{(aq)} + 3Ni_{(s)}}$$

## Activity Series

A metal is oxidized only by ions of metals **below** it on the activity series.

| More Reactive ↑ | Metal |
|---|---|
| | Li |
| | K |
| | Ba |
| | Ca |
| | Na |
| | Mg |
| | Al |
| | Zn |
| | Cr |
| | Fe |
| | Co |
| | Ni |
| | Sn |
| | Pb |
| **← H dividing line** | **H** |
| | Cu |
| | Ag |
| ↓ Less Reactive | Au |

All metals **above H** react with strong acids (H⁺) → H₂ gas. Metals below H (Cu, Ag, Au) do **not**.

$$Zn_{(s)} + 2HCl_{(aq)} \rightarrow ZnCl_{2(aq)} + H_{2(g)}$$

### Activity Series Quick-Check

| Reaction | Result | Reason |
|---|---|---|
| $Ni + Cr^{3+}$ | No reaction | Cr is above Ni |
| $Ni + Sn^{2+}$ | $Ni^{2+} + Sn$ | Sn is below Ni ✓ |
| $2Na + Zn^{2+}$ | $2Na^+ + Zn$ | Zn is below Na ✓ |
| $Na + Ba^{2+}$ | No reaction | Ba is above Na |
| $Au + Na^+$ | No reaction | Na is above Au |

## MCQ Pattern Recognition

| If you see... | It's testing... | Key move |
|---|---|---|
| "Will X react with Y ion?" | Activity series | X reacts only if Y's metal is lower on the list |
| Spectator ions in products | Net ionic equation | Drop all spectator ions |
| LCM of 6 (e.g. Al/Ni, Zn/Au) | Electron balancing | Scale: multiply each half-reaction by the other's electron count |
| Metal + HCl or H₂SO₄ | H dividing line | Only metals above H react; product is H₂ gas |
| "Which is oxidized/reduced?" | OIL RIG | Oxidized = loses e⁻; reduced = gains e⁻ |

---

## FRQ Pattern Recognition

| Part says... | It's asking for... | Key move |
|---|---|---|
| "Write the net ionic equation" | Balanced half-reactions combined | Show half-reactions, balance e⁻, drop spectators |
| "Identify oxidizing/reducing agent" | What gets reduced/oxidized | Oxidizing agent = reduced species; reducing agent = oxidized species |
| "Will a reaction occur?" | Activity series check | State which metal is higher; conclude yes/no |
| "Explain why no reaction occurs" | Activity series reasoning | "X is above Y on the activity series, so X cannot reduce Y^n+" |

## AP Answer Templates

**Reaction occurs:**
> "Zinc is above copper on the activity series, so zinc can reduce Cu²⁺. The net ionic equation is: Zn(s) + Cu²⁺(aq) → Zn²⁺(aq) + Cu(s). Zinc is oxidized (reducing agent); Cu²⁺ is reduced (oxidizing agent)."

**No reaction:**
> "No reaction occurs. Copper is below nickel on the activity series, meaning Cu is not reactive enough to reduce Ni²⁺ ions."

**Identifying agents:**
> "The oxidizing agent is Cu²⁺ because it gains electrons (is reduced). The reducing agent is Zn because it loses electrons (is oxidized)."

---

## Critical Reminders

- OIL RIG: Oxidation Is Loss, Reduction Is Gain
- The **reducing agent** is oxidized; the **oxidizing agent** is reduced — students frequently flip these
- Spectator ions never appear in the net ionic equation
- Use LCM — never leave fractional coefficients in a net ionic equation
- The activity series is a qualitative version of the $E°$ table: higher on the series = more negative $E°$ = stronger reducing agent
- Metals above H dissolve in strong acid; Cu, Ag, Au do not
