# Personal — Home

The main vault. School, life, hobbies, projects, health — all in one place so the connections are visible.

## Areas

- **[[Inbox]]** — capture-anything, sort later
- **[[Journal]]** — daily reflections (`YYYY-MM-DD.md`)
- **[[Goals]]** — life targets, 1yr/5yr, college, career
- **[[People]]** — friends, family, mentors
- **[[College]]** — apps, school research, essays, deadlines
- **[[Projects]]** — personal projects (incl. private agonizing-sentience scratchpad)
- **[[School]]** — AP coursework. AP Chem is built out; APUSH/Psych/Pre-Calc are stubs.
- **[[Entertainment]]** — Books, Movies, Music, TV, Video Games
- **[[Health]]** — Crew (rowing) + general health: Nutrition, Medical, Mental, Sleep, Gym

## External vaults (separate repos)

- **agonizing-sentience** — public, collaborative novel project. The private scratchpad version lives in `Projects/agonizing-sentience/`.
- **card-flip** — TCG reselling business. Private repo.

## Conventions

- Daily-style notes use ISO dates: `YYYY-MM-DD.md`
- Each major area has its own `Home.md`
- `Inbox/` is the default landing for anything you don't know how to file yet
