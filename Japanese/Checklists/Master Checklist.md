# Master Checklist — Beginner → N1

One tickable list for the whole journey. Each stage links to its detail file. Check
boxes as you go; the satisfaction is the point. Milestones are hours-keyed, so progress
at any pace.

## Stage 0 — Foundations ([[Roadmap/Stage 0 - Foundations (Kana + Setup)|detail]])
- [ ] Refresh hiragana to instant recognition
- [ ] Learn katakana to instant recognition
- [ ] Dakuten, combos, long vowels, small っ understood
- [ ] Anki (or free alt) installed, daily review started
- [ ] Yomitan installed in browser
- [ ] Read [[Japanese Master Roadmap]] + [[Weekly Routine]]

## Stage 1 — Beginner / N5 ([[Roadmap/Stage 1 - Beginner (N5)|detail]])
- [ ] N5 grammar complete (Genki I or Tae Kim basics)
- [ ] ~600–700 vocab in SRS
- [ ] ~80–100 kanji recognized in context
- [ ] Read 5+ Tadoku L0 readers
- [ ] 10+ beginner comprehensible-input videos/episodes
- [ ] Read one NHK Easy article with a dictionary
- [ ] Free N5 mock feels comfortable
- [ ] *(optional)* handwrite ~50 most common kanji

## Stage 2 — Upper Beginner / N4 ([[Roadmap/Stage 2 - Upper Beginner (N4)|detail]])
- [ ] N4 grammar complete (Genki II or Tae Kim essential)
- [ ] ~1,500 vocab total
- [ ] ~300 kanji recognized
- [ ] Sentence-mining deck started
- [ ] 10+ Tadoku L2–L3 readers + one easy manga volume
- [ ] Follow a slice-of-life anime episode w/ JP subs
- [ ] Free N4 mock feels comfortable
- [ ] **Free-resource line reached** — reassess any paid tools here

## Stage 3 — Intermediate / N3 ([[Roadmap/Stage 3 - Intermediate (N3)|detail]])
- [ ] N3 grammar complete
- [ ] ~3,000 vocab (much mined from real content)
- [ ] ~650 kanji recognized
- [ ] Mining 3–5 cards/day consistently
- [ ] Finished a manga series OR ~10 anime eps mostly sub-free
- [ ] Read 4+ regular (non-Easy) NHK articles
- [ ] Free N3 mock feels comfortable
- [ ] *(if 18+ & committed)* registered for real N3 — first external checkpoint

## Stage 4 — Upper Intermediate / N2 ([[Roadmap/Stage 4 - Upper Intermediate (N2)|detail]])
- [ ] N2 grammar complete
- [ ] ~6,000 vocab total
- [ ] ~1,000 kanji recognized
- [ ] Native media without subtitles as default
- [ ] Read a full novel (with lookups)
- [ ] NHK regular news comfortable
- [ ] Free N2 mock feels comfortable
- [ ] *(decision)* continue to N1, or stop here proud — see Stage 4 fork

## Stage 5 — Advanced / N1 ([[Roadmap/Stage 5 - Advanced (N1)|detail]])
- [ ] N1 grammar complete (Shin Kanzen Master N1 or equiv)
- [ ] ~10,000+ vocab
- [ ] ~2,000+ kanji recognized
- [ ] Read multiple novels + a nonfiction book
- [ ] Read a daily newspaper comfortably
- [ ] Understand news broadcasts / lectures unaided
- [ ] Pass full N1 mocks consistently
- [ ] *(summit)* sat & passed the real JLPT N1 🎌

## Habit tracker (the thing that actually matters)

The single best predictor of success is the **daily SRS streak**. Track it:

- [ ] 7-day SRS streak
- [ ] 30-day streak
- [ ] 100-day streak
- [ ] 365-day streak
- [ ] 1,000-day streak

> [!tip] If you only do one thing
> Never break the SRS chain. A 5-minute day beats a zero day. Everything in this plan
> compounds off that one habit.
