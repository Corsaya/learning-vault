# Stage 0 — Foundations (Kana + Setup)

**Goal:** Lock in both kana alphabets cold, and build the toolchain you'll use for
years. Short stage (~25 hrs / ~5 weeks at 7hr, ~3.5 at 10hr). Don't skip the setup —
a clean toolchain now saves hundreds of hours later.

> [!note] Your starting point
> Hiragana ~90% but rusty. Katakana not started. So: refresh hiragana, learn katakana,
> set up tools. That's the whole stage.

## What "done" looks like

- [ ] Read any **hiragana** instantly (no chart)
- [ ] Read any **katakana** instantly (no chart)
- [ ] Know dakuten/handakuten (が ぱ), small ゃゅょ combos, long vowels, small っ
- [ ] Anki (or alternative) installed and synced, daily review habit started
- [ ] Yomitan dictionary set up in your browser
- [ ] You've read [[Japanese Master Roadmap]] and [[Weekly Routine]]

## This week (do this first)

1. **Refresh hiragana** — [Tofugu hiragana guide](https://www.tofugu.com/japanese/learn-hiragana/) (free, mnemonic-based). 2–3 short sessions.
2. **Learn katakana** — [Tofugu katakana guide](https://www.tofugu.com/japanese/learn-katakana/). Same method.
3. **Drill** — [Real Kana](https://realkana.com/) or [Kana Pro](https://kana.pro/) daily until instant.
4. **Set up SRS** — see [[Free Resource Stack]] → SRS section. Install, add a kana deck or just start with a starter vocab deck once kana is solid.
5. **Install Yomitan** in your browser for instant word lookups.

## What to use

- **Kana:** Tofugu guides (free) + RealKana/KanaPro drills (free)
- **SRS:** Anki — see [[Paid Options Worth It]] for the iOS situation and free workarounds
- **Dictionary:** [Jisho.org](https://jisho.org) + Yomitan browser extension (both free)

## Handwriting note (your skill track)

If you want handwriting from day one (you ranked it #3): trace kana by hand while
learning them. Kana handwriting is cheap and worth it. **Kanji handwriting is the
expensive part — defer that decision to Stage 1.** For now, write kana freely.

## Don't do yet

- ❌ Don't start kanji as isolated characters. Kanji comes *with vocab* in Stage 1.
- ❌ Don't buy anything. Everything here is free.
- ❌ Don't grind Duolingo as your main path — fine as a snack, not a spine.

## Done when…

You can read a random katakana menu or hiragana sign without thinking, and you've
reviewed your SRS deck for 5+ days straight. → Move to [[Roadmap/Stage 1 - Beginner (N5)|Stage 1]].
