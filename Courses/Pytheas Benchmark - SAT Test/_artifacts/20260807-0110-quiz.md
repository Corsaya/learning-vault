# Algebra Quiz

## Question 1
Given the system of equations below, what is the value of $x$?
$$\begin{cases} x + y = 10 \\ x - y = 4 \end{cases}$$

- [x] 7
- [ ] 3
- [ ] 14
- [ ] 6

**Hint:** Consider what happens to the variable $y$ if you add the two equations together.

## Question 2
A line is defined by the equation $y = -\frac{2}{3}x + 8$. What is the slope of a line that is perpendicular to this line?

- [x] $\frac{3}{2}$
- [ ] $-\frac{2}{3}$
- [ ] $\frac{2}{3}$
- [ ] $-\frac{3}{2}$

**Hint:** Remember that perpendicular slopes must be both flipped as a fraction and changed in sign.

## Question 3
In the linear model $C = 15h + 40$, which represents the total cost $C$ for $h$ hours of service, what does the value $40$ represent?

- [x] The flat fee or initial base charge
- [ ] The hourly rate of the service
- [ ] The total cost after 15 hours
- [ ] The number of hours worked

**Hint:** Think about what the cost would be if zero hours of service were performed.

## Question 4
Solve the following system using substitution:
$$\begin{cases} y = 2x \\ 3x + y = 15 \end{cases}$$

- [x] $(3, 6)$
- [ ] $(5, 10)$
- [ ] $(6, 3)$
- [ ] $(15, 30)$

**Hint:** Try replacing the $y$ in the second equation with the expression provided in the first equation.

## Question 5
Which of the following equations represents a line that is parallel to $y = 5x - 2$?

- [x] $y = 5x + 10$
- [ ] $y = -5x - 2$
- [ ] $y = -\frac{1}{5}x + 4$
- [ ] $y = 2x + 5$

**Hint:** Focus on identifying the part of the equation that determines the steepness and direction of the line.

## Question 6
A gym charges a $\$50$ sign-up fee plus $\$20$ per month. Which equation expresses the total cost $T$ in terms of the number of months $m$?

- [x] $T = 20m + 50$
- [ ] $T = 50m + 20$
- [ ] $T = 70m$
- [ ] $T = m + 70$

**Hint:** Identify which value is a one-time cost and which value repeats every month.

## Question 7
What is the slope of the line represented by the equation $2x + y = 6$?

- [x] $-2$
- [ ] 2
- [ ] 6
- [ ] $\frac{1}{2}$

**Hint:** Try rearranging the equation into the form $y = mx + b$ by isolating $y$.

## Question 8
Using the elimination method, what is the first logical step to solve the following system?
$$\begin{cases} 4x - 3y = 10 \\ 2x + 3y = 8 \end{cases}$$

- [x] Add the two equations together
- [ ] Subtract the second equation from the first
- [ ] Multiply the first equation by 2
- [ ] Divide the second equation by 2

**Hint:** Look at the coefficients of the $y$ terms and see how they relate to each other.

## Question 9
If a rental company charges a $\$30$ base fee and $\$0.10$ per mile, what is the total cost for driving 200 miles?

- [x] $\$50$
- [ ] $\$230$
- [ ] $\$20$
- [ ] $\$6,030$

**Hint:** Calculate the variable cost for the miles driven first, then add the one-time base fee.

## Question 10
Which of the following best describes the relationship between the lines $y = 4x + 2$ and $y = -\frac{1}{4}x + 2$?

- [x] They are perpendicular.
- [ ] They are parallel.
- [ ] They are the same line.
- [ ] They never intersect.

**Hint:** Compare the slopes of the two lines to see if they are identical or negative reciprocals.
