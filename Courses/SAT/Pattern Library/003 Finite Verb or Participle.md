# Pattern 003 — All Choices Are the Same Verb → Finite or Participle?

Difficulty

Medium

Estimated Solve Time

20-30 seconds

Domain

Standard English Conventions

Subskill

Boundaries / Sentence Structure

Evidence

Two misses on [[Bluebook Practice Test — 2026-08-20]] — M2 Q20 and M2 Q21, the same
trap twice in one module.

---

## Recognition

Use this pattern whenever all four choices are forms of the **same verb**.

had prioritized / was prioritizing / prioritized / prioritizing

searched / searching / were searching / have searched

---

## Core Idea

The SAT is not asking about tense.

It is asking whether this sentence already has a main verb.

---

## Algorithm

Step 1

Find the main verb of the sentence.

Ignore the blank.

Step 2

Is there already one?

Step 3

If yes, and there is no FANBOYS and no subordinator,

the blank must be a **participle**.

Cross out every finite form.

Step 4

If no main verb exists yet, the blank **is** the main verb.

Pick the finite form that agrees with the subject.

---

## Memory Rule

One sentence

One main verb

The rest are participles

---

## Why It Works

Two finite verbs with only a comma between them is a comma splice.

A participle is not a finite verb, so it cannot start a second clause.

---

## SAT Traps

The main verb is far away, after a long interrupter.

"scientists ___ for evidence in snakes, species that rely primarily on olfactory
rather than visual processing, **adapted** the test"

The main verb is *adapted*. The blank is *searching*.

Choosing by tense instead of by structure.
