# Pattern 001 — Function Tables → Find the Factor

Difficulty

Medium-Hard

Estimated Solve Time

20-30 seconds

Domain

Advanced Math

Subskill

Polynomial Factors

---

## Recognition

Use this pattern whenever

- function table
- polynomial
- factor
- root
- zero

appear together.

---

## Core Idea

Factors come from roots.

Roots occur where

p(x)=0

---

## Algorithm

Step 1

Ignore every output except zero.

Step 2

Write every x-value where p(x)=0.

Step 3

Flip the sign.

Root 2

becomes

(x-2)

Root -1

becomes

(x+1)

Step 4

Match the answer.

---

## Memory Rule

Zero

↓

Flip

↓

Factor

---

## Why It Works

(x-a)=0

only when

x=a

(x+a)=0

only when

x=-a

The sign always flips.

---

## SAT Traps

Choosing the wrong sign.

Using nonzero outputs.

Trying to reconstruct the polynomial.

Factoring unnecessarily.
