# Adaptive Review System

## Goal

Every practice test should create a personalized study plan.

Every incorrect question must be categorized.

Fields

- Domain
- Subskill
- Pattern
- Difficulty
- Time Spent
- Confidence
- Reason Missed

Reasons include

- Didn't know concept
- Forgot formula
- Misread
- Careless
- Timing
- Vocabulary
- Second guessed

---

## Confidence

🟢 Certain

🟡 Unsure

🔴 Guess

Interpretation

Green wrong = knowledge gap

Yellow wrong = needs repetition

Red correct = lucky guess

## English Rule Vault

Whenever grammar causes a miss

Automatically add the governing rule to [[English Rule Vault]].

Never memorize individual questions.

---

## Pattern Detection

Generate summaries such as

"I miss scatterplots."

"I spend too long on quadratics."

"My grammar mistakes are commas."

Use these summaries to generate future study plans and new entries in the [[Pattern Index]].

For execution guidance during the next practice test, use [[Test Day Execution]].
