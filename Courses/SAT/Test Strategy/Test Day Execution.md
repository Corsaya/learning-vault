# Test Day Execution

## Philosophy

Treat every Bluebook practice test exactly like the official SAT.

The objective is not to achieve a certain score.

The objective is to collect the highest quality data possible.

Every mistake becomes an opportunity to improve before the official exam.

Success after a practice test should be measured by answering:

- What did I learn?
- What patterns did I find?
- What weaknesses became obvious?
- What should I study next?

A lower practice score with excellent analysis is more valuable than a higher score with poor review.

---

# Simulating the Real SAT

Before beginning:

- Eat a normal meal.
- Use the same calculator.
- Water nearby.
- Scratch paper.
- Phone away.
- Quiet room.
- Complete the test in one sitting.

Treat the practice test exactly like Saturday.

---

# Reading & Writing Mindset

Reading & Writing is NOT a reading test.

It is a decision-making test.

Every question asks one of four things.

- Which answer is supported?
- Which grammar rule applies?
- Which sentence fits?
- Which word belongs?

The passage is evidence.

Not the assignment.

---

# Detective Mentality

Never read simply to read.

Instead ask:

"What is this question asking me to prove?"

Workflow

1. Read question.
2. Identify task.
3. Find evidence.
4. Choose answer.

---

# One Question At A Time

Never think

"I have 27 questions."

Think

"I'm solving Question 12."

Then Question 13.

Each question is its own mission.

---

# Athlete Mentality

Like rowing a 2k:

Don't think about 2000 meters.

Think about the next ten strokes.

Do the same on the SAT.

One question.

Reset.

Next question.

---

# Question Classification

🟢 Immediate

Answer immediately.

🟡 Workable

Continue working.

🔴 Time Sink

Flag immediately.

Move on.

---

# Three Pass Strategy

Pass 1

Solve everything straightforward.

Skip hesitation.

Pass 2

Return to skipped questions.

Use Desmos.

Backsolve.

Plug numbers.

Pass 3

Finish remaining difficult questions.

---

# Review Mindset

Never ask

"What score did I get?"

Ask

"What mistake will never happen again?"

---

# Execution Goal

Don't chase a 1400.

Make one good decision.

Repeat hundreds of times.
