# Courses

This folder is managed by **Pytheas → Courses**. Each subfolder is a
course; files dropped into the app land here and become NotebookLM
sources. Generated study material (podcasts, videos, quizzes, flashcards,
study guides, mind maps) is saved in each course's `_artifacts/`.

It's a normal vault folder — link to course files from School notes
freely. Reorganizing by hand is fine too; use "Sync sources" in Pytheas
afterwards so NotebookLM picks up new files.
