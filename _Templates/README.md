# Templates

How to use these in Obsidian:

1. Settings → Core plugins → enable **Templates**.
2. Settings → Templates → set "Template folder location" to `_Templates`.
3. In a new note, run command **"Templates: Insert template"** (default hotkey: `Cmd/Ctrl + P` then search).

`{{date:YYYY-MM-DD}}` and `{{title}}` are auto-filled by Obsidian on insert.

## What's here

| Template | Use for |
|---|---|
| Journal Entry | Daily reflection in `Journal/` |
| Person | Profile in `People/` |
| Crew Training Entry | Daily training log in `Health/Crew/Training Log/` |
| Crew Race Report | Race in `Health/Crew/Races/` |
| Entertainment - Book | One per book in `Entertainment/Books/` |
| Entertainment - Movie | One per movie in `Entertainment/Movies/` |
| Entertainment - TV Show | One per show in `Entertainment/TV Shows/` |
| Entertainment - Video Game | One per game in `Entertainment/Video Games/` |
| Entertainment - Album | One per album in `Entertainment/Music/` |

## Notes on the templates

- All entertainment templates have a "One-line take" first. If a one-liner is all you ever write, that's fine — that's the **log mode**. Add to "Notes" for **review mode**. Build out sub-folders (like One Piece) for **deep mode**.
- "Connects to" at the bottom of entertainment templates is for cross-vault links (a book → its movie, a game → an arc you wrote about). The whole point of the mega-vault.
- Crew training entry is intentionally light — your existing entries are loose narrative ("Morning:/Afternoon:") and that's working. Template adds optional structure without forcing it.
- Race report is the opposite — heavier structure because races deserve real analysis if you're chasing recruiting.
