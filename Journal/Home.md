# Journal

Daily entries. Organized by academic year → month.

## Years

- [[2025-2026 (Junior Year)/Home|2025-2026 — Junior Year]]
- [[2026-2027 (Senior Year)/Home|2026-2027 — Senior Year]]

## How to use

1. New entry: create `YYYY-MM-DD.md` inside the correct `YYYY-MM - Month/` subfolder.
2. Use the **Journal Entry** template (`_Templates/Journal Entry.md`).
3. Fill in `locations:` and `mood:` in the frontmatter — these power the tag filters.
4. `grade:` field: `junior` through end of May 2026, `senior` from August 2026 onward.

## Tag reference

| Tag | When to use |

| `school` | School day — classes, homework, school social |
| `crew` | Practice, erg, water session |

| `work` | Card-flip business work |

| `college-visit` | Campus visit or info session |
| `away` | Away from home (travel, trips) |
| `travel` | Extended travel |
| `ap-exam` | AP exam day |
| `milestone` | Something important happened |
| `college` | College app / decision event |
