# Super Prompt — first operating review

The [Super Prompt](../Super%20Prompt.md) has been applied as a first cross-vault review. Its roles are review responsibilities, not separate autonomous agents. This produced an archive, reconciled context, a homework audit, official admissions checks, an income baseline and a constrained project addendum. It did not create a continuously running service or complete the user's personal tasks by declaring them planned.

## Evidence and maintenance rules

Keep a dated fact separate from a goal, a user-reported result separate from a verified report, and a historical assistant proposal separate from a user decision. Newer statements update the working context only where they actually address the same fact; they do not erase history.

Each subsequent review should record: completed work with evidence; missed work without inferred excuses; nearest verified deadline; one next action; one thing to defer. Useful triggers are a score report, completed packet, new assignment, race result or real job listing. A short weekly review is a proposed cadence, not an automation already installed.

Existing authoritative notes were not rewritten or globally deduplicated. Their conflicts are documented in the private context note so they can be reconciled with evidence. The public novel and personal journal were not used as places to generate new prose. No email, application, training intervention or financial transaction was performed.
