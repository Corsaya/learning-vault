## Daily schedule — summer template

Blocks, not clock times — anchor them to your real wake time. Assumption to
correct: ~3 productive deep-work blocks/day is sustainable; more is a sprint,
not a schedule.

| Block | Length | What |
|---|---|---|
| Morning deep work | 90 min | **AP Chem.** Hardest thing first, phone elsewhere. |
| Skill block | 60 min | Rotate: ML ladder ↔ jarvis codebase (alternate days) |
| Japanese | 25 min | Kana production drills — daily, short, never skipped |
| Afternoon build | 90 min | Project of the week: journal-app spec, content rep, jarvis improve |
| Physical | 45 min | The health habit |
| Evening review | 10 min | Journal capture + tick this checklist + tomorrow's one priority |

Rules that make it survive:
- **One priority per day**, named the night before. Everything else is bonus.
- Japanese and the evening review are the only *never-skip* blocks — they're
  short on purpose so the streak survives bad days.
- When school starts: morning deep work becomes homework triage, skill block
  drops to 3×/week, everything else holds.
