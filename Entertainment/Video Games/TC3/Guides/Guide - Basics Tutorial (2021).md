## Mechanics covered (all consistent with reference ✅)
- **Select:** click-drag highlight; Ctrl+click queues multiple move commands; press **T** to jump to your Command Center.
- **Building placement:** every building must be near an existing friendly building *or* a friendly unit + crystal. Naval Shipyard must sit on sand (green = placeable, red = invalid).
- **Income:** Power Plant +$10 CPM, Nuclear +$15 CPM (regular crystal) — matches reference. Occupy *every* nearby crystal; an idle crystal is $10–15 CPM wasted.
- **Construction Soldier → press N near water** makes a build point; then Naval Shipyard ($80) on the sand edge.
- **Caps:** 10 troops / 25 buildings base; **Soldier House** → +1 soldier cap. ✅
- **Command Center:** lose it and you can't use allies' production. ✅ (reference confirms)
- **CC garrison/sell:** sell buildings for partial refund when being overrun.

## Unit/building notes (✅ vs reference)
- **Heavy Soldier $20** — "better light soldier," recommended default. ✅
- **Turret $65** ("laser") — ground/plane defense. ✅
- **Naval Shipyard $80.** ✅ · **Hovercraft** = amphibious, carries 2, fast, great early. ✅ · **Aircraft Carrier** = plane factory at sea. ✅ · **Oil Ship** → N on black oil dots = income. ✅
- **Submarine** via research; only Destroyers (and subs) can hit them. ✅
