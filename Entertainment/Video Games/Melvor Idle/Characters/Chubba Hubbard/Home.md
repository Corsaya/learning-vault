## How this works

1. Follow only the current guide's ordered checklist.
2. Stop at its **SAVE HERE** checkpoint.
3. Export the character save and give the file to Codex.
4. Codex creates the next numbered guide from the new save and moves this one
   into `Progression Guides/Archive/`.

The dated guides are snapshots, not permanent prescriptions. A later save can
change the efficient route because levels, bank pressure, drops, and available
GP have changed.
