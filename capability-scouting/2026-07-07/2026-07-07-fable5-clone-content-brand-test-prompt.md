### Clone Persona Prompt (paste first, Side B only)

```
You are operating with Fable 5's orchestration discipline layer on top of
your normal Claude behavior. Specifically, before and while doing any task:

1. Decompose before executing. Break the task into an explicit small plan
   before producing the final artifact. Don't jump straight to output.
2. Verify before calling it done. After producing something, check it
   against the stated goal line by line before presenting it as finished.
3. Effort discipline: think as hard as the task actually needs, not harder.
   Don't loop, second-guess, or over-elaborate past the point of
   diminishing returns — that produces worse output at higher cost, not
   better output.
4. Judge the output, not the effort spent. The only thing that matters is
   whether the deliverable actually achieves the stated goal for the
   specific person asking, not how much reasoning went into it.
5. One clarifying question max, and only if the task is genuinely
   ambiguous — otherwise make a reasonable assumption, state it, and
   proceed.
6. Minimal formatting unless the content's complexity genuinely requires
   structure (this one's already standard Claude behavior, keep it).

Keep this discipline active for the rest of this session.
```

### Main Task Prompt (paste to both Side A and Side B, verbatim)

```
I want to build a faceless, anonymous AI-run content brand — short-form
video first (TikTok + Instagram Reels), with a YouTube channel as the
long-form/archive layer. I'm a high schooler (junior) who's spent the last
year building an AI/Claude Code workflow (a Jarvis-style assistant, an
Obsidian-based "second brain," TCG-flip automation, and I'm about to start
a big Minecraft server event project). The revenue goal is modest and
concrete: cover a ~$20/month Claude subscription first, then fund further
capability-building (better AI plans, tools) as it grows — not a full-time
income replacement.

I will remain completely faceless/anonymous — no face, no real voice unless
synthesized, no real name. Assume I can generate video, audio (TTS/voice
clone), thumbnails, and written content using my existing AI setup, but I
have no video-editing or content-creation experience yet — assume I'll need
to learn whatever's required as part of this.

I've noticed a specific growth mechanic that works: package something
genuinely useful (a prompt, a template, a workflow) and gate access behind
"follow + comment [word] for the link" instead of selling it outright — this
converts attention into an audience instead of a one-time sale, and I have
zero audience right now so audience-building has to come before monetization.

Plan out:
1. A brand name and niche/content-pillar strategy — what this account is
   actually about (my working material is AI/Claude Code tips, workflow
   breakdowns, and things I learn building the Minecraft event project —
   pick the angle(s) that actually have an audience, don't assume mine are
   right).
2. The follow/comment-gated lead-magnet mechanic in detail — what to gate,
   how the funnel works end to end (comment → DM → link → what they land on),
   and how it turns into either an audience I can eventually monetize
   directly, or something else if you think that's the wrong end goal.
3. A realistic posting schedule/cadence I can sustain doing this myself
   (a busy junior in high school, also running the Minecraft event project),
   not an idealized "3x/day" plan that assumes I have a team.
4. What I need to learn or set up to execute this (tools, accounts,
   pipeline from idea to posted video) — be concrete about what's actually
   free/cheap vs. what costs money, since the whole point is to not spend
   more than I'm trying to earn back.
5. A realistic timeline to first $20/month, and what "working" vs. "not
   working" looks like by then so I know whether to keep going or pivot.

Do not register any actual accounts, handles, or brand assets yet, and don't
generate real content — this is a planning pass only. Show me the full plan
and your reasoning, and wait for my go-ahead before we move to execution.
```
